# Использование ИИ

- Использован ИИ: да, Claude (Sonnet 5), интерфейс приложения Claude Code (desktop).
- Затронутые файлы: README.md, `.github/workflows/ci.yml`, `.gitignore`,
  `evidence/pr01/graph.md`, `evidence/pr01/environment.json`,
  `evidence/pr01/report.json`, эта декларация.
- Помощь ИИ:
  - установка и починка окружения на Windows 10 (WSL2, переустановка сломанного
    дистрибутива Ubuntu, запуск Docker Desktop, включение WSL-интеграции,
    проверка проброса графики WSLg);
  - подготовка команд опыта и скриптов для сбора показаний в
    `evidence/pr01/` (без изменения самих ROS-команд из методички курса);
  - оформление README, `graph.md`, `report.json` и данной декларации по
    фактическим результатам запусков.
- Что сделано лично, без автоматизации: три реальных нажатия клавиши ↑ в
  интерактивном терминале `turtle_teleop_key` — исходное движение, попытка
  движения при пульте в чужом `ROS_DOMAIN_ID` (контрольная проверка отсутствия
  связи) и движение после восстановления домена; переключение
  `ROS_DOMAIN_ID` на пульте выполнялось вручную по указанным командам.
  `turtle_teleop_key` требует интерактивный терминал (падает без него:
  `Failed to get old console mode`) и поэтому не мог быть автоматизирован —
  это не решение, а техническое ограничение самой программы.
- Проверка: все файлы в `evidence/pr01/` — реальный stdout и коды завершения
  запущенных команд в контейнере с образом
  `osrf/ros:lyrical-desktop-full@sha256:e6b1cb53...9df3ebe`, ничего не
  сгенерировано вместо фактического запуска. Значения координат черепахи в
  `graph.md` взяты непосредственно из соответствующих файлов `pose-*.txt`.

Переписка, личные промпты и секреты не включены.
